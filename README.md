# Task Manager API

REST API для управления личными задачами на FastAPI и PostgreSQL.
Пользователи регистрируются, входят с помощью JWT и управляют своими
задачами. Каждый пользователь видит только свои данные.

## Возможности

- Регистрация и вход с JWT-аутентификацией (Bearer)
- Пароли хранятся в виде хешей Argon2
- CRUD для задач: заголовок, описание, статус, приоритет, срок выполнения
- Фильтрация по статусу и приоритету, пагинация (`limit` / `offset`)
- Валидация данных через Pydantic, единый формат ответов об ошибках
- Миграции базы данных через Alembic
- Автотесты (pytest) и CI на GitHub Actions
- Поддержка Docker и Docker Compose

## Технологии

Python 3.12, FastAPI, SQLAlchemy 2, PostgreSQL, Alembic, Pydantic v2,
PyJWT, pwdlib (Argon2), pytest, Docker, GitHub Actions.

## Структура проекта

```
app/
  api/        роуты и зависимости (авторизация, сессия БД)
  core/       настройки, безопасность (JWT, хеширование), исключения
  db/         подключение к БД, сессии, модели SQLAlchemy
  schemas/    схемы Pydantic (запросы и ответы)
  services/   бизнес-логика
alembic/      миграции базы данных
tests/        тесты pytest
```

Код разделён на слои: роуты отвечают за HTTP, сервисы содержат логику и
работают с базой данных, схемы проверяют данные.

## Запуск

### Вариант 1: Docker (рекомендуется)

```
docker compose up --build
```

API будет доступен по адресу http://127.0.0.1:8000, документация — по адресу
http://127.0.0.1:8000/docs. Миграции применяются автоматически при старте.

Пароли в `docker-compose.yml` предназначены только для локального запуска.
Не используйте их в продакшене.

### Вариант 2: Локально

1. Создайте две базы данных PostgreSQL, например `task_manager` и
   `task_manager_test` (в названии тестовой базы должно быть слово `test`).
2. Создайте виртуальное окружение и установите зависимости:

```
   python -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # Linux / macOS
   pip install -r requirements.txt
```

3. Скопируйте `.env.example` в `.env` и укажите свои значения.
4. Примените миграции и запустите сервер:

```
   alembic upgrade head
   uvicorn app.main:app --reload
```

### Переменные окружения

| Переменная | Описание | Значение по умолчанию |
|---|---|---|
| `DATABASE_URL` | URL подключения к PostgreSQL | обязательная |
| `TEST_DATABASE_URL` | База для тестов (в названии должно быть `test`) | нет |
| `JWT_SECRET_KEY` | Секрет для подписи токенов | обязательная |
| `JWT_ALGORITHM` | Алгоритм JWT | `HS256` |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | Время жизни токена в минутах | `30` |

## Обзор API

| Метод | Путь | Описание | Авторизация |
|---|---|---|---|
| POST | `/auth/register` | Создать аккаунт | нет |
| POST | `/auth/login` | Получить токен доступа | нет |
| GET | `/users/me` | Текущий пользователь | да |
| POST | `/tasks` | Создать задачу | да |
| GET | `/tasks` | Список своих задач | да |
| GET | `/tasks/{id}` | Получить задачу | да |
| PATCH | `/tasks/{id}` | Обновить задачу | да |
| DELETE | `/tasks/{id}` | Удалить задачу | да |

Параметры запроса `GET /tasks`: `status_filter` (`new`, `in_progress`,
`done`), `priority_filter` (`low`, `medium`, `high`), `limit` (от 1 до 100,
по умолчанию 20), `offset`.

Защищённые эндпоинты ожидают заголовок `Authorization: Bearer <token>`.
Проще всего всё попробовать в интерактивной документации `/docs`:
зарегистрируйтесь, войдите, нажмите **Authorize** и вставьте токен.

Чужая задача возвращается как `404 Not Found`, поэтому API не раскрывает,
существует ли она.

## Тесты

```
pip install -r requirements-dev.txt
pytest
```

Тесты работают с отдельной базой PostgreSQL (`TEST_DATABASE_URL`):
таблицы создаются и удаляются вокруг каждого теста.
